# Pilot 2: frozen evidence v0.2.1 on a held-out arrangement (2026-10-20)

Raw data and analysis are local only (`data/raw/` is gitignored): `data/raw/2026-10-20-pilot2/` holds the captures in `pi/`, the capture helper `shot.sh`, and `analysis/` (`pilot2_table.md`, `PRE_RUN.json`, `jobs.json`, `truth.json`, `evidence.jsonl`, `diagnostics.jsonl`). An independent check reproduced every number below.

**What "held out" covers.** The evidence code (`perception/evidence.py` 0.2.1, sha256 `d0e0927f…`) was frozen on 2026-10-16, four days before the photos. The target boxes and the truth labels were written after capture and before the evidence run (`PRE_RUN.json`). The occluders were chosen on purpose to probe a known weakness. So this is a held-out test of the code, not a random sample, and it is small: one arrangement, one stop, 8 non-visible pairs.

## Capture

- **Session:** `2026-10-20-pilot2`, arrangement PILOT02, stop P3 only, a new arrangement.
- **Lighting:** the reference was shot at L1 (all lights, 195 lux); the 13 queries at L2 (one light off, 66–69 lux).
- **Targets:** top cup, chess clock, bottom mug, Bulbasaur plush. Each is shown occluded, removed and put back.
- **Occluders:** a plain white box (Bulbasaur, clock), the Clorox canister (top cup), a book (mug).
- **Retake:** the first cup-removal photo still showed the cup. It was kept and labelled visible, and the removal was re-shot as take 2.
- **Registration:** tags 0/1/3; RMS 0.13–0.21 px on all 13 queries.

The study's stopping rule needs two clear-miss stops before REMOVED (k = 2). On this one-stop pilot it would say UNKNOWN for the four removals and for the clock, which is 47/52. ## The miss: a white box over the chess clock

The clock behind the white box was called REMOVED (match 0.49, obstruction 0.15).

- **The detector did see the box** (class `box`, confidence 0.553). But the box covered almost exactly the clock's outline (IoU 0.583 with the clock's box), so the rule that treats detections with IoU ≥ `target_iou` (0.5) as "the target itself" discarded it. Without that exclusion, the detector cue would have been 0.85.
- **Novelty was low (0.15)** because the box's flat white faces match the white shelf, panel and back wall in the reference window.
- **This is a structural gap** that the v0.2.1 known-limits text does not describe: any occluder with about the same footprint as the target is invisible to the detector cue. The Bulbasaur, behind the same box, passed only on novelty (0.34 against 0.3); there the detector really did miss the box.

The same mechanism recurs on public data (10 of 36 same-footprint occlusions in OCID dev; [OCID note](2026-10-23-public-data-ocid.md)). Any fix (evidence v0.3) makes pilots 1 and 2 development data, so a new held-out set is needed to test it.
