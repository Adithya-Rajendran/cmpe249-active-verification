# Object and software credits

The simulation images use textured YCB-Video object models in BOP format.
The study placed the meshes in synthetic shelf and tabletop scenes. It rendered new RGB images and instance masks.

Berk Calli, Arjun Singh, Aaron Walsman, Siddhartha Srinivasa, Pieter Abbeel, and Aaron M. Dollar created the YCB object set.
The YCB authors distribute the data under Creative Commons Attribution 4.0 International.
[Original YCB distribution](https://ycb-benchmarks.s3.amazonaws.com/index.html) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

Yu Xiang, Tanner Schmidt, Venkatraman Narayanan, and Dieter Fox introduced YCB-Video.
The BOP distribution provides the mesh files used for rendering and identifies their source.
[YCB-Video](https://rse-lab.cs.washington.edu/projects/posecnn/) · [BOP distribution and credits](https://bop.felk.cvut.cz/datasets/)

NVIDIA Isaac Sim and MuJoCo supplied the two renderers. The study used the same object arrangements in both.
[NVIDIA Isaac Sim](https://developer.nvidia.com/isaac/sim) · [MuJoCo](https://mujoco.org/)

The supplement includes the study code, derived images, and measurements.
The software guide lists the separate sources for upstream models and checkpoints.
